# تطوير قسم الحفظ والمستندات — 2026-09-24

هذا الملف مرجع إلزامي لقسم **الحفظ والمستندات** في تطبيق مكتبة أبو بسام.

## محرر الصور المتقدم
- لكل صورة محفوظة يظهر زر «تحرير متقدم».
- القص الحر يتم بالسحب المباشر لمربع القص وأربع زوايا، وليس بواسطة Sliders فقط.
- يوجد تصحيح منظور حقيقي بأربع نقاط يعتمد Homography projective mapping.
- توجد أدوات: دوران، إضاءة، تباين، تشبع، حرارة/توازن اللون، إزالة التشويش، Sharpen، وقبل/بعد.
- المعالجة النهائية تستخدم الصورة الأصلية من IndexedDB، وليس صورة المعاينة المصغرة.
- يجب تطبيق حدود أمان للذاكرة على الصور الكبيرة.
- بعد الحفظ يصبح الملف `syncState=pending` ليدخل دورة المزامنة من جديد.

## OCR المحلي
- OCR يدعم العربية والإنجليزية (`ara+eng`).
- النسخة المبنية Android يجب أن تحتوي Tesseract.js worker/core وبيانات اللغتين داخل `android/app/src/main/assets/library/vendor/tesseract`.
- تجهيز الملفات يتم أثناء `npm run assets:android` من `scripts/prepare-android-assets.mjs`.
- مسارات Runtime تكون محلية: `vendor/tesseract/...`.
- بعد بناء APK بنجاح لا يحتاج OCR إلى الإنترنت في أول استخدام أو الاستخدامات اللاحقة.
- نسخة المصدر قبل تنفيذ خطوة تجهيز Android قد لا تحتوي الملفات الثنائية الكبيرة؛ خطوة البناء ملزمة بتنزيلها وتضمينها أو تفشل صراحةً.

## الخزنة الخاصة المشفرة
- الخزنة المشفرة منفصلة عن الأرشيف العام حتى لا تكسر توافق الملفات الحالية.
- تستخدم AES-GCM.
- المفتاح مشتق من كلمة مرور المستخدم باستخدام PBKDF2/SHA-256 بعدد 250,000 دورة.
- كلمة المرور لا تخزن.
- مفتاح AES لا يخزن في IndexedDB أو LocalStorage أو سجل العمليات؛ يحتفظ به في الذاكرة فقط أثناء فتح الخزنة.
- يتم قفل الخزنة ومسح المفتاح عند اختيار «قفل» وعند انتقال الصفحة إلى حالة hidden.
- الملفات داخل الخزنة تحفظ ciphertext + IV + metadata فقط.
- فتح الملف أو حفظ نسخة يتطلب فك التشفير بعد فتح الخزنة.
- الخزنة محلية خاصة بهذا الجهاز في هذه المرحلة؛ لا يجوز رفع نسخة مفكوكة التشفير إلى السحابة تلقائيًا.

## الفحص الإلزامي
