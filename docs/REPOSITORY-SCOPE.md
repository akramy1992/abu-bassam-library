# نطاق المستودع

هذا المستودع هو المرجع الرسمي لتطبيق **مكتبة أبو بسام للتصوير والقرطاسية**.

- المصمم والمبرمج: **أكرم حاتم الغزالي**.
- لا توضع هنا ملفات تطبيق **مساعد المعلم** أو ملفات **Phone.Max** أو أي مشروع آخر.
- كل تعديل على التطبيق يجب أن ينعكس في المصدر و`CHANGELOG.md` ووثيقة التدقيق عند الحاجة.
- لا تعتبر الميزة «تمت» إلا بعد وجودها فعليًا في المصدر ونجاح فحص المشروع.
- ملفات `output/` و`tools/__pycache__/` نواتج اختبار محلية وليست جزءًا من المصدر المعتمد.

## صيغة التدقيق المعتمدة

- تم ✅: موجود فعليًا وتم التحقق منه.
- ناقص ⚠️: موجود جزئيًا أو لا يحقق كامل المتطلب.
- غير موجود ❌: لم يتم تنفيذه في المصدر.
- يحتاج تحقق 🔍: لا توجد أدلة كافية لاعتماده.
