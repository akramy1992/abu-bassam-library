# نطاق المستودع

هذا المستودع هو المرجع الرسمي لتطبيق **مكتبة أبو بسام للتصوير والقرطاسية**.

- المصمم والمبرمج: **أكرم حاتم الغزالي**.
- لا توضع هنا ملفات مشاريع أخرى.
- التوثيق يصف المتطلبات الحالية ولا يثبت نجاح التنفيذ.
- السجل التاريخي يبقى في Git history ولا يُعاد استخدامه كدليل تحقق.

## حالات التدقيق
- `متحقق آليًا ✅`: يوجد اختبار آلي ناجح يمكن تحديد اسمه وCommit/Run الذي نفذه.
- `متحقق ميدانيًا ✅`: توجد تجربة فعلية موثقة على الجهاز أو الأداة المطلوبة.
- `ناقص ⚠️`: التنفيذ جزئي أو لا يغطي كامل المتطلب.
- `غير موجود ❌`: لا يوجد تنفيذ يحقق الطلب.
- `يحتاج تحقق 🔍`: لا توجد أدلة كافية على العمل الفعلي.

## ممنوع
- اعتبار وجود زر أو ملف أو دالة دليلًا على نجاح الميزة.
- استخدام `تم ✅` كحكم عام على ميزة.
- استخدام عبارات `مكتمل` أو `جاهز 100%` أو `يعمل 100%` بدون اختبار يثبت النطاق المقصود.
- نسخ حالة نجاح من تقرير قديم إلى تقرير جديد بدون إعادة الفحص.

عند كل تدقيق يجب إرفاق مصدر الدليل أو ترك الحالة `يحتاج تحقق 🔍`.
