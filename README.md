## قاعدة التحقق
وجود الكود أو الواجهة لا يساوي نجاحًا فعليًا. التحقق الآلي يثبت فقط ما يغطيه الاختبار. الوظائف التي تعتمد على الهاتف أو الكاميرا أو الطابعة أو QR أو سلوك WebView الفعلي تبقى `يحتاج تحقق 🔍` حتى التجربة على الجهاز المناسب.

## البناء
```bash
npm ci --no-audit --no-fund
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleRelease --no-daemon
```
