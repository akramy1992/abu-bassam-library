# مكتبة أبو بسام — Android 4.3.2

تطبيق عربي لمكتبة أبو بسام للتصوير والقرطاسية. المصمم والمبرمج: **أكرم حاتم الغزالي**. الحزمة `com.abubassam.librarycamera3`، الإصدار `4.3.2`، build `432`.

## الأقسام
صوري والطباعة، البطاقة الوطنية والمستمسكات، **الباركود والكروت**، الحفظ والمستندات، صياغة الأسئلة، ضغط الصور، الإعدادات والأمان والسجل.

## الباركود والكروت
يحتوي أدوات التصميم المعتمدة: الباج التعريفي، الروضة/المدرسة، تسجيل الدخول/الإيميل، Wi‑Fi، QR، البطاقة التموينية، المواكب، الظرف، شهادات التقدير، كتاب الشكر. يوجد زر **🧩 النماذج** عام وزر نماذج خاص بكل قسم.

الأعداد: التعريفي 5، الروضة 10، تسجيل الدخول 10، Wi‑Fi 3، QR 4، **التموينية 10، المواكب 4، الأظرف 9، شهادات التقدير 10، الشكر 6**.

## صياغة الأسئلة
قسم مستقل للأسئلة فقط، عربي RTL / إنجليزي LTR، قوالب وأنواع أسئلة، A4/A5/مخصص، حفظ وطباعة/PDF. الظرف والشكر والشهادات ليست داخله. الأسئلة وضغط الصور Lazy-load.

## الأمان وبدء التشغيل
Splash watchdog على الويب وWebView، حقول الدخول LTR، منع المحاولة المكررة من ضغطة واحدة، عدم احتساب أخطاء الجهاز ككلمة مرور، SecureStore وبصمة وإدارة أجهزة. WebView محلي فقط والروابط الخارجية تفتح خارج التطبيق الداخلي.

## البناء
```bash
npm ci --no-audit --no-fund
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleRelease --no-daemon
```

GitHub Actions يبني Release standalone ويؤكد وجود `assets/index.android.bundle` والتوقيع، ويولد SHA-256. الـworkflow read-only ولا ينشئ commits تلقائيًا. الـAPK الناتج يبقى Artifact لمدة 14 يومًا ولا يُحفظ داخل شجرة المشروع.

نجاح CI لا يغني عن اختبار الهاتف والطابعة والكاميرا وQR الفعلي.
